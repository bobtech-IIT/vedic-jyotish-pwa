# Jyotish Acharya – Vedic Astrology PWA

A Progressive Web App for generating an educational Vedic (sidereal) birth chart (Janam Kundli) and consulting a virtual Acharya for interpretive guidance rooted in classical Jyotisha, the philosophical vision of the Upanishads, and the sense of cosmic order found in the Vedas.

## Features

- Birth data form (name, gender, date, time, place with major city presets + manual coordinates)
- Client-side approximate Lahiri ayanamsa calculations for Lagna, planetary positions, nakshatras and a simplified Vimshottari dasha balance
- North Indian style diamond chart rendered in SVG
- Planetary position table
- Virtual Acharya Vedant – keyword-aware interpretive responses with clear educational framing and disclaimers
- Fully installable PWA with offline support after first load
- All birth data remains on the device

## Important Disclaimer

The planetary and dasha calculations are **educational approximations** using simplified astronomical formulae. They are **not** Swiss-Ephemeris grade and should not be used for professional consulting, muhurta, or medical/financial decisions.

The virtual Acharya offers **interpretive guidance** based on traditional principles. It does not claim literal possession of the entire corpus of the Vedas or Upanishads. Responses are generated from structured knowledge of classical Jyotisha themes and philosophical orientation. Free will, personal effort, and qualified human guidance remain paramount.

## Deployment

This is a static site. Deploy to:

- GitHub Pages
- Netlify / Vercel / Cloudflare Pages
- Any static file host

Simply upload the contents of this folder or push to the repository and enable Pages on the `main` branch.

## Local Use

Open `index.html` in a modern browser, or serve the folder with any static server:

```bash
npx serve .
```
